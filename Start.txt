Common gotchas

Ports already in use → stop old processes or change ports in infra/docker-compose.yaml.

DB schema didn’t re-init → you likely have a persisted volume (expected). If you truly need a clean DB:

docker compose -f .\infra\docker-compose.yaml down
docker volume rm moviemix_pgdata   # ⚠️ deletes DB data
docker compose -f .\infra\docker-compose.yaml up -d --build db


Recommender says “Index not built” → rebuild once:

Invoke-RestMethod http://localhost:8001/admin/build_embeddings -Method Post -ContentType "application/json" -Body '{"limit":200}'
